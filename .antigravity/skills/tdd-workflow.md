# Skill: Fluxo TDD (Red -> Green -> Refactor)

Conduza a implementação seguindo Test-Driven Development estrito.

## Passos
1. **RED:** Antes de escrever código de produção, crie testes automatizados pequenos e objetivos descrevendo o comportamento esperado (incluindo 1 caso de sucesso e os principais edge cases/erros). Rode os testes e confirme que falham pelo motivo certo.
2. **GREEN:** Escreva o código mínimo necessário para fazer todos os testes passarem.
3. **REFACTOR:** Melhore legibilidade, tipagem e estrutura mantendo todos os testes verdes.
4. **VERIFICAÇÃO:** Rode a suíte completa de testes e linter antes de finalizar.
